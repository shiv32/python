Python is a high-level, interpreted, open-source programming language created by Guido van Rossum and first released in 1991. 
It is known for its simple, readable syntax, making it one of the easiest languages to learn. 
Python is widely used for:

    Web development (Django, Flask, FastAPI)
    Automation and scripting
    Data analysis and visualization
    Artificial Intelligence and Machine Learning
    Scientific computing
    Desktop and command-line (CLI) applications

Python has a large standard library, a huge ecosystem of third-party packages (via pip), and runs on Windows, Linux, and macOS. 
It is maintained by the Python Software Foundation (PSF).
