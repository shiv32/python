# Python Domains (No Embedded)

Python can be used in web, cloud, desktop, and server-side development without working with embedded systems or hardware.

## 1. Python application domains


1. Web Backend Development

* Frameworks: Django, FastAPI, Flask

* REST APIs, authentication, database integration

* Applications: E-commerce, SaaS, web services



2. Cloud Development

* Technologies: AWS, Azure, Google Cloud

* Cloud APIs, serverless functions, cloud automation

* Applications: Cloud services, scalable applications



3. Server-Side and Backend Infrastructure

* Technologies: Python, Linux, PostgreSQL, Redis

* Applications: Background workers, task queues, logging services, network services

* Tools: Celery, Gunicorn, Uvicorn



4. Desktop Application Development

* Frameworks: PySide6, PyQt, Tkinter

* Applications: Desktop utilities, management software, business applications

* Supports Windows and Linux desktop applications



5. DevOps and Cloud Automation

* Technologies: Python, Docker, Kubernetes, CI/CD

* Applications: Deployment automation, infrastructure management, monitoring


## 2. Technology stack by domain

1. Web Backend
   Frameworks: Django, FastAPI, Flask

2. Cloud
   Technologies: AWS SDK (Boto3), Azure SDK

3. Server Infrastructure
   Technologies: Linux, Celery, Redis

4. Desktop
   Frameworks: PySide6, PyQt, Tkinter

5. DevOps
   Technologies: Ansible, Docker SDK, Cloud SDKs


## 3. Common career roles

* Python Backend Developer

* Python Software Engineer

* Cloud Automation Engineer

* DevOps Engineer

* Python Desktop Application Developer

* Backend Infrastructure Developer

Summary: For a non-embedded Python career, focus on Python + FastAPI/Django + SQL + Linux + cloud technologies. 
This combination covers web applications, server-side services, and cloud-based systems.
